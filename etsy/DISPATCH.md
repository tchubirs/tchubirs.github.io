# Task: open an Etsy shop and publish twenty-two digital-download listings

You are acting in the user's own browser, on the user's behalf. Everything to
publish is already made: spreadsheet files, guides, photos and listing texts.
Your job is only to set up the shop and create the listings exactly as written.

## Stop and ask the user before any of these

- **Money:** the one-time shop setup fee, listing fees, or any card or payment
  details. The user enters card and bank details themselves.
- **Identity:** ID or identity checks, and phone or e-mail verification codes.
- **Shop name:** the shop name (it is public). Suggest three from the list
  below and let the user choose.
- **Anything else** not covered here, including any Etsy page that asks for
  the user's legal or tax status. Never invent answers.
- Never turn on paid ads (Etsy Ads, Offsite Ads opt-in beyond the default) or
  subscriptions (Etsy Plus).
