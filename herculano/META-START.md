## Developer background

Independent solo creator based in France. I build WebXR experiences with AI
coding tools. My current project is a hands-first mixed-reality title for
Meta Quest, built with Meta's Immersive Web SDK (IWSDK). The code is public
on GitHub.

## Project details

**Name:** Herculaneum

**Platform:** Meta Quest (WebXR, built with IWSDK). Mixed reality with a VR
fallback.

**Stage:** Playable prototype. The full loop works end to end, with automated
tests in the IWSDK emulator.

**Description:** A scroll burnt by Vesuvius in AD 79 appears on the player's
real table, found through scene understanding. The player pinches the charred
roll and pulls it open, then sweeps an open palm just above the papyrus. A
scanner light follows the hand, and the invisible ink glows letter by letter
until the player finds the hidden Greek word. A new scroll comes every day.
It is hands only, seated, and needs no controllers.

**Planned launch:** Web now; Meta Horizon Store (PWA) in the first quarter of
2027. It will also be entered in the Meta VR Start Developer Competition 2026.
