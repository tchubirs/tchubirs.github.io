## Passo 1: criar a conta e o perfil

1. Abra o link, clique em **Become a Seller** e entre com a sua conta Google.
2. **Nome de usuário** (não dá para mudar depois). Escolha um neutro, por exemplo: `scriptdesk`, `tidyscript` ou `datapipe_studio`.
3. **Foto:** uma foto sua com o rosto aparecendo.
4. **Description:**

```
I build small tools for data and office work: Python scripts, web scrapers, and Google Sheets or Excel automations with formulas, Apps Script or VBA. Scraped data is delivered as an Excel, CSV or JSON file. I use AI tools to work faster, and I test every script and file on real data before I send it. We agree on the scope and the price before you order. If the delivery does not work as agreed, I fix it. All communication is in written English.
```

5. **Languages:** Portuguese (Native) e English. No inglês, coloque o seu nível real.
6. **Occupation:** Programming & Tech, a partir de 2026.
7. **Skills** (adicione um por um):

```
Python
Web Scraping
Data Extraction
Google Sheets
Microsoft Excel
Google Apps Script
VBA
Automation
```

8. Educação e certificados: pule.
9. Confirme o e-mail e o telefone quando pedir.
