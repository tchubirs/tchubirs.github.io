Privacy Policy

Last updated: September 28, 2026

postador is a personal tool used only by its owner to publish videos to his own social media accounts.

What data is accessed

  • OAuth tokens for the owner's own YouTube, Instagram, Facebook and TikTok accounts.
  • Basic account details needed to identify the connected account, such as channel or account name and ID.
  • The videos, captions and titles the owner chooses to publish, and the resulting post links and status.

How data is used

Data is used only to upload and publish the owner's content to the owner's accounts and to report whether each post succeeded. It is not used for advertising, profiling, analytics resale or any other purpose.

Storage and security

Tokens are stored on the owner's own computer, or in an encrypted file (AES-256-GCM) whose key is kept separately in private settings. Tokens are never published in plain text.

Sharing

No data is sold, shared with or transferred to third parties. Data is only sent to the platform it belongs to (for example, a video sent to YouTube).

Google API Services

postador's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the stored token file removes all saved access.
