Política de Privacidade

Última atualização: 14 de setembro de 2026

1. Resumo

Esta ferramenta é usada por uma única pessoa — o dono desta conta — sobre a sua própria conta do TikTok. Não recolhe dados de mais ninguém. Não há registo de utilizadores, não há visitantes com conta, não há base de dados de pessoas.

2. Que dados são tratados

Apenas o estritamente necessário para enviar vídeos para os rascunhos do dono:

  • Tokens de acesso do TikTok (access token e refresh token), obtidos quando o dono autoriza a aplicação na sua própria conta.
  • Ficheiros de vídeo que o próprio dono produziu ou está autorizado a usar.
  • Identificadores técnicos devolvidos pelo TikTok para cada envio (por exemplo o publish_id), para saber se o envio chegou.

3. Que dados NÃO são tratados

  • Nenhum dado de outros utilizadores do TikTok.
  • Nenhum comentário, mensagem, lista de seguidores ou contacto.
  • Nenhum dado de visitantes deste site: não há cookies, não há analytics, não há rastreamento.

4. Onde ficam guardados

Os tokens ficam guardados como segredos encriptados no repositório privado do dono no GitHub (GitHub Actions Secrets), acessíveis apenas ao dono. Os ficheiros de vídeo existem apenas durante a execução e são apagados quando ela termina.

5. Partilha com terceiros

Nenhuma. Os dados não são vendidos, alugados nem partilhados. A única comunicação externa é com a própria API do TikTok, para fazer o envio.

6. Durante quanto tempo

Os tokens ficam guardados enquanto o dono quiser usar a ferramenta. O dono pode revogar o acesso a qualquer momento nas definições do TikTok (Definições e privacidade → Segurança e permissões → Apps autorizadas), e pode apagar os segredos do GitHub, o que destrói os tokens de imediato.

7. Direitos

Como o único titular dos dados é o próprio dono da ferramenta, qualquer pedido de acesso, correção ou eliminação é satisfeito por ele próprio, de imediato, pelos meios descritos no ponto 6.

English summary

This is a private, single-user tool operated by the owner of this account on their own TikTok account. It collects no data from anyone else. The only data handled are: the owner's own TikTok OAuth access and refresh tokens, the owner's own video files, and the technical publish identifiers returned by TikTok. No other TikTok users' data is accessed; no comments, messages, follower lists or contacts are read. This website sets no cookies and runs no analytics. Tokens are stored as encrypted GitHub Actions Secrets in the owner's private repository; video files exist only for the duration of a run and are then deleted. Nothing is sold, rented or shared with third parties — the only outbound communication is with the TikTok API itself. The owner can revoke access at any time in TikTok Settings → Security and permissions → Manage app permissions, and can delete the stored secrets, which destroys the tokens immediately.
